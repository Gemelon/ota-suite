WLAN einrichten

Verbinden Sie das Geraet mit einem WLAN mit Internetzugang. Der geschuetzte Einrichtungs-Access-Point bleibt als Rueckweg aktiv.

Leer fuer offenes WLAN; sonst 8-63 Bytes oder 64 Hex-Zeichen.

Beim Wechsel des WLAN-Kanals kann die AP-Verbindung kurz abbrechen. Danach ggf. erneut mit dem Access Point verbinden. Zugangsdaten werden im Geraet gespeichert.
